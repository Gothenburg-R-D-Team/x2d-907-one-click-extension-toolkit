# 升级前先恢复 / Restore before upgrading

## 中文

**务必、务必、务必：相机已经安装本工具扩展时，升级软件前先使用原电脑、原软件版本执行“一键恢复原状”。确认恢复完成后，再升级电脑端软件并重新安装相机扩展。**

虽然本软件支持在**相同软件版本**下跨电脑恢复，但为了避免一切不必要的麻烦，升级时仍务必先使用原电脑、原软件版本恢复。跨电脑恢复的支持不表示可以跨软件版本覆盖、安装或恢复，也不替代以下升级顺序。

### 正确顺序

1. 保留安装相机上当前扩展时使用的**原电脑、原软件版本、完整安装包及相关备份**。“原软件版本”指本工具版本，不是相机原厂固件版本。
2. 在原电脑打开原版本工具包，连接相机，按该版本说明执行 **已连接 → 一键恢复原状**。操作中保持稳定供电和连接。
3. 等待原版本软件明确报告恢复完成。若失败或状态不明确，停止后续升级，先确认恢复方案；不要把恢复失败当成已经恢复。
4. 确认完成后，再手动升级电脑端软件，或使用 App 内的 **下载安装更新**。恢复完成前，不要覆盖、卸载或删除原软件及备份。
5. 打开新版，核实其明确支持您的机型和固件，并按新版说明使用 **已连接 → 一键安装** 安装相机扩展。检查更新、下载新版或替换电脑端 App 本身不代表相机扩展已完成更新。

**原电脑 + 原软件版本恢复 → 确认完成 → 升级软件 → 重新安装扩展。**

### 原电脑或原版本无法使用时

暂停升级，保留现有软件、安装记录和备份，通过 [Issues](https://github.com/radium-wang/x2d-907-one-click-extension-toolkit/issues) 确认恢复方案。不要先用新版本覆盖、强行安装或尝试跨版本恢复。同版本跨电脑恢复可作为需要核实条件的替代方案，不应将其理解为任意电脑、任意安装包都能恢复。

首次安装、相机没有本工具扩展时，无需先恢复已有安装。从内测版转向稳定版也必须先使用**原电脑及原内测版本**恢复，再安装稳定版。

“恢复原状”仅撤回本工具管理的改动，不能保证修复所有故障或找回照片。完整风险、担保排除和责任限制见[中文免责声明](DISCLAIMER.zh-CN.md)。请勿在公开问题中粘贴序列号、个人信息或未经检查的完整日志。

## English

**Before upgrading a camera that already has this toolkit's extension, you must run “Restore original” using the original computer and the original Software version. Confirm completion before upgrading the desktop Software and reinstalling the camera extension.**

Recovery on another computer is supported when using the **same Software version**. Nevertheless, always restore first using the original computer and original version before an upgrade to avoid unnecessary problems. Cross-computer recovery does not imply support for overwriting, installing or restoring across Software versions and does not replace the sequence below.

### Required sequence

1. Keep the **original computer, original Software version, complete package and relevant backups** used to install the extension currently on the camera. “Original Software version” refers to this toolkit, not the manufacturer's camera firmware.
2. Open that version on the original computer, connect the camera and follow its instructions for **Connected → Restore original**. Maintain stable power and connection during the operation.
3. Wait until the original app explicitly reports that restoration has completed. If recovery fails or the status is uncertain, stop the upgrade and confirm a recovery approach first. A failed recovery is not a completed recovery.
4. Only after completion, upgrade the desktop Software manually or through the in-app **Download and Install Update** action. Do not overwrite, uninstall or delete the original Software or backups before recovery is complete.
5. Open the new release, verify its stated camera and firmware support, then follow its instructions for **Connected → Install**. Checking for updates, downloading a new release or replacing the desktop app does not itself update the camera extension.

**Original computer + original Software version: restore → confirm completion → upgrade Software → reinstall extension.**

### If the original computer or version is unavailable

Pause the upgrade, retain existing Software, installation records and backups, and ask through [Issues](https://github.com/radium-wang/x2d-907-one-click-extension-toolkit/issues) for a confirmed recovery approach. Do not overwrite the old version, force an installation or attempt cross-version recovery first. Same-version recovery on another computer is a possible alternative whose conditions must be checked; it is not a promise that any computer or package can restore an installation.

A first installation on a camera without this toolkit's extension does not require restoration of an existing installation. Moving from a private beta to stable also requires restoration using the **original computer and original beta version** before stable installation.

“Restore original” withdraws changes managed by this tool; it cannot guarantee repair of every fault or recovery of photographs. See the [full risk notice and disclaimer](../DISCLAIMER.md). Do not post serial numbers, personal information or unreviewed complete logs in public issues.
